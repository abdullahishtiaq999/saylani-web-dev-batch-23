### 1. Product Names — `map()`

Create a new array containing only product names.

**Expected output:**

```
[
  "iPhone 15",
  "Galaxy S24",
  "MacBook Air M3",
  "Dell XPS 13",
  "AirPods Pro",
  "Galaxy Buds",
  "HP Pavilion",
  "Samsung A55"
]
```

### 2. Product Prices — `map()`

Create a new array containing only the product prices.

**Expected output:**

```
[
  250000,
  220000,
  350000,
  280000,
  65000,
  35000,
  180000,
  120000
]
```

### 3. Formatted Products — `map()`

Return each product in this format:

```
Product Name - Rs. Price
```

**Expected output:**

```
[
  "iPhone 15 - Rs. 250000",
  "Galaxy S24 - Rs. 220000",
  "MacBook Air M3 - Rs. 350000",
  "Dell XPS 13 - Rs. 280000",
  "AirPods Pro - Rs. 65000",
  "Galaxy Buds - Rs. 35000",
  "HP Pavilion - Rs. 180000",
  "Samsung A55 - Rs. 120000"
]
```

### 4. Add Discount — `map()`

Create a new array of product objects and add a `discountedPrice` property with a **10% discount**.

Do **not** modify the original objects.

**Expected output shape:**

```
{
  id: 1,
  name: "iPhone 15",
  category: "Mobile",
  price: 250000,
  stock: 10,
  brand: "Apple",
  rating: 4.8,
  discountedPrice: 225000
}
```

Expected discounted prices:

```
[
  225000,
  198000,
  315000,
  252000,
  58500,
  31500,
  162000,
  108000
]
```
